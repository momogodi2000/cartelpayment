# Pawelium 2.0 — Internationalization & Terminology Glossary

This glossary defines standard, authoritative translations and conventions for bilingual English (`en`) and French (`fr`) copy across Pawelium. All public, customer, administrative, and transactional email copy must adhere strictly to these terms.

---

## 1. Core Domain Terminology

| English (`en`) | French (`fr`) | Context & Guidelines |
|---|---|---|
| **Animal** | **Animal** (pl. **Animaux**) | Primary generic noun for all dogs, puppies, cats, kittens. Never use "Produit" or "Article". |
| **Dog / Puppy** | **Chien / Chiot** | Canine listings. "Chiot" when age < 6 months. |
| **Cat / Kitten** | **Chat / Chaton** | Feline listings. "Chaton" when age < 6 months. |
| **Breeder** | **Éleveur** (fem. **Éleveuse**, pl. **Éleveurs**) | Certified European partner breeder. Never use "Fournisseur" or "Vendeur". |
| **Kennel / Cattery** | **Élevage / Chatterie** | Registered breeding facility. |
| **Availability** | **Disponibilité** | Stock / adoption status of an animal listing. |
| **Available** | **Disponible** | Listing ready for adoption. |
| **Reserved / Hold** | **Réservé / En cours de réservation** | Temporary 15-minute checkout hold or active reservation. |
| **Sold / Adopted** | **Adopté** (or **Vendu**) | Finalized purchase. Prefer "Adopté" on public UI; "Vendu" on admin/legal. |
| **Reservation (Hold)** | **Réservation** | Time-locked inventory hold during checkout. |
| **Order** | **Commande** | Commercial transaction record (`PW-XXXXXXXXXX`). |
| **Payment** | **Paiement** | 100% upfront card transaction via GeniusPay. |
| **Refund** | **Remboursement** | Approved return of funds. |
| **Delivery / Transport** | **Livraison / Transport spécialisé** | Temperature-controlled European pet transport. |
| **Customer Support** | **Service client** / **Concierge** | Adopter assistance portal and ticket system. |
| **Email Verification** | **Vérification par e-mail** | 6-digit OTP verification code. |
| **Animal Documentation** | **Documents de l'animal** | ICAD certificate, EU Pet Passport, pedigree, health inspection. |
| **Microchip / ICAD** | **Puce électronique / ICAD** | Official animal identification number. |
| **EU Pet Passport** | **Passeport européen pour animaux** | Official veterinary health & vaccination passport. |
| **Health Guarantee** | **Garantie de santé** | Statutory European veterinary conformity guarantee. |
| **Terms of Sale** | **Conditions Générales de Vente (CGV)** | Legal contractual terms governing adoption. |

## 2. French Typography & Editorial Rules

1. **Vouvoiement Strict:**
   Always address adopters using the formal "vous" (*"Votre commande"*, *"Consultez vos documents"*), never "tu".
2. **Punctuation & Non-Breaking Spaces:**
   In French, all two-part punctuation marks (`:`, `;`, `?`, `!`, `»`, `%`, `€`) must be preceded by a non-breaking space (or thin space).
   - Correct: `Total : 1 600,00 €`
   - Incorrect: `Total: 1600.00€`
3. **Accentuated Capital Letters:**
   Always retain accents on capital letters in French: `Éleveur`, `À propos`, `État`, `Éthique`.
4. **Number & Currency Formatting:**
   - English: `€1,600.00` or `1,600.00 EUR`
   - French: `1 600,00 €` (comma as decimal separator, non-breaking space as thousands separator).
